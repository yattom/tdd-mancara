# 0003 言語と開発ツール

- 日時：2026-11-13 13:26

## 決めたこと

- 言語は Python 3.15 とする。型ヒントをしっかり書く。
- パッケージ管理は uv。`src/` レイアウトで、パッケージ名は `mancala`。
- テストは pytest。
- リンターとフォーマッタは Ruff。ルールはデフォルトに I（import 順）、B（バグになりやすい書き方）、UP（新しい書き方への移行）、SIM（単純化）を足す。
- 型チェックは mypy の strict モード。
- 依存は正確なバージョンで固定し、`exclude-newer = "2 days"` で公開2日未満のバージョンを避ける。

## 背景と理由

- やっとむが Python に慣れていて好き。uv も入っていて、環境づくりに時間がかからない。
- pytest の `parametrize` で、1つの仕様に対する複数パターンをまとめて書ける。TODO リストのインデント構造と合う。
- Hypothesis などで、TDD 以外のテスト手法も取り入れやすい。
- Ruff はリンターとフォーマッタを1つで担えて、入れるツールが少なくて済む。
- mypy は最初から strict にしておくほうが、後から厳しくするより楽。

## 検討した他の案

- **TypeScript + pnpm + Vitest**：使えるが、コンパイルやモジュールの設定など決めることが少し多い。
- **型チェッカーに Pyright**：速いが、内部で Node.js を使う。
- **型チェッカーに ty（Astral）**：安定度に確信が持てない。
