# 0005 Board は外部から immutable に見えるように振る舞う

- 日時：2026-11-13 14:35

## 決めたこと

- Board は、外部（公開 API）からは immutable に見え、そのように振る舞う。
- 盤面を変える操作（`move()`、`move_a_stone()`）は、元の盤面を変えずに新しい盤面を返す。
- 内部が変更可能かどうかは問わない。オブジェクトとして真に immutable にすることは、今は求めない。

## 背景と理由

- immutable かどうかは、言語機能とは別のレベルの設計判断である。
- 外部から immutable に振る舞う設計（内部は変更可能）から、真に immutable な設計への変更は容易。逆向きの変更は影響が大きそう。
- 公開 API の振る舞いはテストで確かめるので、内部の設計は後から変えられる。

## 検討した他の案

- **オブジェクトとして真に immutable にする**（`@dataclass(frozen=True)` と tuple など）：構造で保証でき、ハッシュ可能にもできる。一方、状態全体を渡して生成する手段が要り、内部表現や実装の書き方の選択肢が狭まる。
