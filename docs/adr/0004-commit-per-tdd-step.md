# 0004 TDD のステップごとのコミットとコミットメッセージ

- 日時：2026-11-13 13:40

## 決めたこと

- Red、Green、Refactor のそれぞれでコミットする。
- 各ステップで最低1回コミットする。
- 間違いの修正や追加の変更があれば、1つのステップで複数回コミットしてよい。
- コミットメッセージの先頭に、変更の種類を表すプレフィックスを付ける（Conventional Commits の形式）。
  - `test:` テストの追加・変更（Red）
  - `feat:` 機能の追加（Green）
  - `refactor:` 振る舞いを変えない設計の改善
  - `fix:` 間違いの修正
  - `docs:` ドキュメント
  - `chore:` 環境や設定など、上記以外
- プレフィックスの後ろの本文は日本語で書く。

## 背景と理由

- コミットのプレフィックスは、t-wada さんが話していたやり方を取り入れる。

## 検討した他の案

- **Green になってからまとめてコミットする**：Red の状態が履歴に残らない。
