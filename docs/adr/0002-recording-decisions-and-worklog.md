# 0002 意思決定と作業記録の残し方

- 日時：2026-11-13 12:58

## 決めたこと

- 意思決定は略式の ADR として `docs/adr/` に残す。1つの決定を1ファイルにし、1ページ程度に収める。
  - 書く項目は「決めたこと」「背景と理由」「検討した他の案」「日時」だけにする。
  - ファイル名は `NNNN-<slug>.md` とする。
- それとは別に、作業ログを `docs/worklog.md` に残す。やったこと、考えたこと、試行錯誤を、形式にこだわらず時系列に書いていく。
- worklog から ADR は参照してよい。ADR から worklog は参照しない。

## 背景と理由

- 演習の目的の1つが、意思決定の履歴と結論を残すことである。
- 決定の結論と、そこに至るまでの過程は、読む目的が違う。結論は ADR に短くまとめ、過程は worklog に置く。
- worklog は必要なときに参照するメモである。ADR は worklog を読まなくても理解できるようにしておく。

## 検討した他の案

- **1つのファイルに決定を時系列で追記していく**：手軽だが、決定と作業のメモが混ざり、結論を探しにくい。
- **正式な ADR 形式（ステータスや影響の項目まで書く）**：2時間のセッションで細かい決定が多く出ると見込まれ、量に対して重すぎる。
